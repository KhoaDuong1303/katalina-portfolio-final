UPDATE YOUR GITHUB REPOSITORY
1. Copy every file and folder in this package into the root of your katalina-portfolio repository.
2. Replace the older files when Finder asks.
3. In GitHub Desktop, use the summary: Embed Who Am I video.
4. Click Commit to main, then Push origin.

NETLIFY
If Netlify is connected to the GitHub repository, it will redeploy automatically after the push.
